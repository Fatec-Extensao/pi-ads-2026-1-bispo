# Projeto Integrador — ADS — FATEC Lins

Repositório oficial do Projeto Integrador do curso de Análise e Desenvolvimento
de Sistemas da FATEC Lins, organizado por semestre letivo.

## Sistema

O Projeto Integrador tem como objeto um sistema de pesquisas por questionários.
O escopo funcional detalhado, os integrantes e os resultados acadêmicos serão
documentados quando forem oficialmente definidos, sem registrar funcionalidades
ainda não implementadas.

## Semestres

- [2026-1](./2026-1/): histórico, documentação e código do primeiro semestre.
- [2026-2](./2026-2/): organização das disciplinas e entregas do segundo semestre.
- [Plano de entregas da Atividade 06](./2026-2/PLANO-DE-ENTREGAS.md): acompanhamento das Issues por disciplina.

Os artefatos acadêmicos serão adicionados somente após a confirmação de que
pertencem a este projeto. A migração do material de 2026-1 permanece pendente.

Toda documentação acadêmica deste repositório deve ser escrita em Markdown.
Imagens e diagramas podem usar `.png`, `.svg` ou `.jpeg`; scripts de banco de
dados podem usar `.sql`; e o código-fonte pode usar os formatos exigidos pela
implementação. Arquivos `.docx`, `.xlsx`, `.pptx` e `.pdf` não devem ser
adicionados. Quando um documento externo for necessário, deve-se usar um link
público.

As pastas vazias `assets/imagens` e `2026-2/desenvolvimento-web/src` são mantidas
no Git por arquivos `.gitkeep` até que existam artefatos reais.
