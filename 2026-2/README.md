## Estrutura de entregas

Cada disciplina possui uma pasta própria e um README para registrar sua
finalidade, seu responsável e os artefatos esperados. Os prazos e resultados das
entregas permanecem pendentes até sua confirmação.

```text
├── README.md

│   │   └── sitemap.md

    └── README.md
```

## Padrão de documentação

Relatórios, requisitos, atas, riscos, segurança, LGPD e modelagem devem ser
documentados em Markdown. Imagens e diagramas podem usar `.png`, `.svg` ou
`.jpeg`; scripts de dados podem usar `.sql`; e o código-fonte pode usar os
formatos necessários. Não devem ser adicionados arquivos `.docx`, `.xlsx`,
`.pptx` ou `.pdf`.
